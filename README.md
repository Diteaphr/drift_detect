# Drift Detection

A Python project for detecting data drift in machine learning models.

## Project Structure

```
drift_detect/
├── src/              # Source code
├── tests/            # Unit tests
├── data/             # Data files
├── requirements.txt  # Python dependencies
└── README.md        # This file
```

## Setup

1. Create a virtual environment:
   ```bash
   python -m venv venv
   ```

2. Activate the virtual environment:
   - macOS/Linux: `source venv/bin/activate`
   - Windows: `venv\Scripts\activate`

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running Tests

```bash
pytest tests/
```
