以 smoke 換算正式約 9,752 次；先維持 4 workers

正式矩陣為原定 8,868 次加 A5u 884 次，共 9,752 次：injected 8,800、INSECTS abrupt 17、INSECTS incremental 15、synthetic HT 680、synthetic hf10 240。Y 的一次 dev 不納入。依 smoke runtime 線性換算，前四組共約 101,900 CPU 秒（28.3 CPU 小時）：injected 以 3→50 trials 乘 50/3，兩個 INSECTS 以全長 52,848／57,018 筆除以 5,000，synthetic HT 以 100,000／5,000。4 workers 的理想下限約 7.1 小時，不含資料載入、輸出與 hf10。此次實測每 worker 峰值 RSS 最高 444.7 MB；正式先沿用 smoke 成功的 4 workers，並用 --resume 保護中斷進度。

hf10 未短跑，時間估計不具實測基礎。 階段一曾粗估 hf10 另需 20–60 CPU 小時；若沿用該規劃區間，總量約 48–88 CPU 小時，4 workers 理想約 12–22 小時。考慮長串流非線性成本與 I/O，先預留 15–30 小時作執行排程，並在正式首批完成後依實測更新；此為容量規劃，非完成時間承諾。來源：階段一資源估計、本次逐筆稽核。
