DET2：warning 期間持續學習改善 A1、A4 準確率，但 Dual ADWIN 未追上 A3、A4

主結論： 在 DET1 固定的單棵 Hoeffding Tree、205 條配對串流下，開啟 warning 期間持續學習後，Dual ADWIN（A1）的全串流 prequential accuracy 提高 0.456 個百分點（95% CI [+0.240, +0.670]），RDDM（A4）提高 0.282 個百分點（CI [+0.066, +0.506]）；HDDM-A（A3）提高 0.050 個百分點，CI 跨 0，判為持平。點估計排序 A1 > A4 > A3 與事前 lw0 凍結步數排序一致。A1-lw1 對 A3-lw1、A4-lw1 的 FP 與 X 兩條件皆為不利、CI 不跨 0，故 Q2 未追上，判不如。將 A1 的 drift delta 改成 0.01 雖使 FP 減少 188，仍未改變 DET1 中 A3/A4 優於 A1 的判定。

分析依 DET2 預註冊事前鎖定的三組分層、串流配對 bootstrap 10,000 次、seed 20261012，95% percentile CI 包含 0 即持平。DET1 verdict與階段三完整性紀錄提供前輪結果及本輪 run 來源。全串流 accuracy 含五條 INSECTS；FP、X 與 drift 後 accuracy 只用 204 條有 GT 串流。CI 描述本批串流的條件不確定性，不代表全新資料的外推區間。

正式輸出可追溯，失敗與缺漏均為零

DET2 新跑的固定程式 commit 為 55bfc81999c98954ad5a4b4aa05df691faac0cff，DET1 沿用來源 commit 為 0b98e29a708ee55f3bcc7f47165696981aa2e282；所有 manifest 工作樹乾淨、River 0.21.2。新跑 820／820、0 失敗：第一批 180／180、2,091 秒；第二批 640／640、1,113 秒，總計 3,204 秒（53 分 24 秒）。每臂都有 160 injected、40 synthetic、5 INSECTS；有 GT 的 204 條配對、無 GT 的 1 條描述。分析逐 run 驗證 preset、source SHA-256、registry、版本、配對 y_true、warning 守恆及原 evaluator TP/FP/FN；lw0 偵測總數與 DET1 summary 交叉核對。詳見逐 run 分數、彙總資料與 CI、正式完整性紀錄及重現閘門／smoke。正式原始 run 在本機 git-ignored outputs/benchmark/det2/，與 DET1、smoke 隔離。

評分仍用 DET1 的含端點 1,000 步窗 [d_s,d_s+1000]；injected 的 GT／警報採原始 input 座標且前 25% 警報不計分。每個 drift 最多算一次 episode hit，C=Σ(1−exp(−FP/O·|W_i|))、X=hits−C。四個 synthetic 暖機前 GT 排除後，正式偵測母體共 473 個可計分 GT。配對 bootstrap 依資料組保留 160／40／4 條有 GT 串流；全串流 accuracy 則保留 160／40／5 條。沒有因結果改窗、選串流或調參。

偏離與口徑釐清不改主要判定

階段二 CLI 的 --cells 子字串匹配，使固定抽中的 5 條 synthetic 之外額外跑出 4 條 × 3 組＝12 次 lw0 檢查 run。預先抽中的 15 條／45 次逐位元閘門仍全部通過；額外 run 留在隔離檢查目錄，不進任何正式計分或 CI。正式 820 次沒有偏離、失敗或缺漏。

DET2 預註冊對 drift 後 accuracy 的文字寫「最多 1,000 個可觀測預測」；DET1 已提交的實際分析程式則以 GT 起點後 1,000 個座標步建立窗，injected 使用原始 input 座標，被注入刪除的列沒有預測，故該窗可能少於 1,000 個預測。本輪為保持與 DET1 完全相同，沿用其實際程式口徑，並在主表註解明示。這只影響次要 drift 後 accuracy 的解讀；Q1 主要全串流 accuracy 與 Q2/Q3 的 FP、X 判準不使用此欄。

事後觀察指出 delta 與訓練機制的代價，不新增判準

  • A1d 的 lw0 凍結步數為 3,728,743，高於 A1 原版的 1,717,081；其確認 buffer 中位長度為 353 對 33。這與 delta=0.01 下更長的 warning 持續狀態一致，但 detector 狀態與 error 回饋也一起變動，不能將 accuracy 下降單獨歸因於凍結。
  • 空 GT INSECTS incremental 上，A1 的 lw1 accuracy 低於 lw0；它與整體 Q1 的 A1 改善方向不同，不能以整體結果保證每條串流受益。
  • A4 的 lw1 FP 比 lw0 少 48，CI [−95, −3] 全負；X 減少約 6.37，但 CI 跨 0。這是次要偵測指標，並未作為 Q1 準確率勝負門檻。

證據只涵蓋鎖定的單棵樹與已使用資料

本輪只有單一 Hoeffding Tree，不外推到森林或其他學習器。synthetic 曾用於 E 系列，是參數鎖定後評估，不是新 holdout；injected 每格只取 registry 前 20 trials。Dual ADWIN 採 River 0.21.2 實作，不能直接等同 MOA 或其他版本。Q2 的「不如」只依本輪預註冊的 FP 與 X 判準；各型態、INSECTS 子組的 CI 是描述性分層，不提供分布外效果保證。
