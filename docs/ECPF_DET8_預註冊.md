# DET8 預註冊：同一個 HDDM-A 工作點下，凍結參照（G3）對 leader（H3）

**登記：** 2026-10-20（Asia/Taipei），以本文件的 commit 為準。各組在判定資料上的任何執行，都在本文件與計分腳本提交之後才開始。本文件提交後不改寫，偏離一律追加在末尾「修訂」。

**頂層問題：** [DET7](ECPF_DET7_判定.md) 的 G3 在三份注入資料上誤報都比 HDDM-A（H）少，electricity 的超額命中沒有差別。但 G3 的 HDDM-A 用 drift 信賴度 3e-4，H 用預設的 0.001。所以 DET7 分不出 G3 的誤報優勢是來自 E10bFT 的機制（凍結參照、leader 守衛、逾時），還是只來自比較保守的工作點。本輪把偵測器和工作點固定為 HDDM-A 3e-4，只改它讀的東西，回答：

1. 同樣用 HDDM-A 3e-4，讀凍結參照並加上守衛的 G3，偵測有沒有比只讀 leader 的 H3 好？
2. 只把 HDDM-A 調保守（H3 對 H），能不能得到 DET7 裡 G3 對 H 的誤報優勢？
3. 在相同誤報下，G3 是否比 leader 訊號抓得多？

背景來源：
- [DET7 預註冊](ECPF_DET7_預註冊.md)、[DET7 判定](ECPF_DET7_判定.md)
- B2、B3-dev 的開發檢查見 DET7 預註冊第四節

## 一、名詞

以下名詞的定義和 [DET7 預註冊第一節](ECPF_DET7_預註冊.md)相同，計分沿用 DET3 的同一組函式：警報、GT、命中、誤報（FP）、碰運氣的期望命中（C）、超額命中（X）、平均偵測延遲（MDT）、整條串流準確率、凍結參照、leader 守衛、短窗、長窗、trial、超出碰運氣。本輪另外用到：

| 名詞 | 意思 |
|---|---|
| 工作點 | HDDM-A 的 drift 信賴度。warning 信賴度固定為它的 5 倍，和 river 預設的比例相同 |
| 連線檢查 | 把 H3 和 H 在誤報－超額命中平面上的兩點連成直線，在 G3 的誤報數上讀出這條線的 X，再和 G3 的 X 相減（第五節） |

## 五、判定規則

### 主判定：electricity，640 條，短窗，G3 對 H3

| 條件 | 量 | 成立 | 不成立 | 持平 |
|---|---|---|---|---|
| P1 誤報 | `ΔFP = FP(G3) − FP(H3)`，640 條合計 | 95% CI 上界小於 0 | 下界大於 0 | 其餘，含碰到 0 |
| P2 超額命中 | `ΔX = X(G3) − X(H3)`，640 條合計，短窗 | 95% CI 下界大於 0 | 上界小於 0 | 其餘，含碰到 0 |

**CI 的算法：** 和 DET7 相同。以串流為單位、兩組配對、有放回抽樣 10,000 次，種子 `20261012`，取第 2.5 和 97.5 百分位；單一資料集不分層，合併時依資料集分層；各組自己的 X 的 CI 用同一批抽樣算。

| P1 | P2 | 結論 |
|---|---|---|
| 成立 | 成立 | G3 優於 H3 |
| 不成立 | 不成立 | G3 不如 H3 |
| 一個成立、一個不成立 | | 有得有失 |
| 任一持平 | | 持平 |

**可判定性：** 和 DET5、DET7 相同。兩組的 X 都沒有超出碰運氣時，P2 記「不可判定」，結論只依 P1 寫。

**結論可以怎麼寫：**
- 「優於」：在相同的 HDDM-A 工作點下，E10bFT 的機制（凍結參照、守衛、逾時）比只讀 leader 的偵測好。不能寫成「凍結參照本身較好」，因為守衛和逾時也不同（第二節）。
- 「持平」：在這個工作點下，E10bFT 的機制沒有帶來可測到的偵測差異。DET7 裡 G3 對 H 的誤報優勢，可以用工作點解釋。
- 「有得有失」：照實寫哪一項較好、哪一項較差。這時兩組只是落在不同的誤報水準，主判定本身分不出是機制還是工作點，要一起看連線檢查。
- 「不如」：照寫。
- 範圍限於「注入漂移的真實資料串流、單棵 Hoeffding Tree、警告期間暫停訓練、HDDM-A 3e-4」，並註明 3e-4 是看過開發資料後替凍結參照挑的。

### 次要判定

以下各項用同一套 P1、P2 和可判定性規則，各自判定，不改變主判定：

1. **covertype，320 條，短窗，G3 對 H3。**
2. **gas，320 條，短窗，G3 對 H3。**
3. **長窗：** 三個資料集各一次，G3 對 H3。窗長和 DET7 相同（2500、2500、1500）。
4. **只調工作點：** 三個資料集各一次，短窗，H3 對 H。
5. **重做 DET7 的比較：** 三個資料集各一次，短窗，G3 對 H。
6. **三資料集合併：** 1,280 條，短窗，G3 對 H3，依資料集分層。

主判定和次要判定方向相反時，兩邊都保留、都寫出來。

### 連線檢查（次要，描述性）

每個資料集各算一次，短窗：

- `gap = X(G3) − [X(H3) + (FP(G3) − FP(H3)) × (X(H) − X(H3)) / (FP(H) − FP(H3))]`，各量都是該資料集全部串流的合計。
- 只在 `FP(H3) < FP(G3) < FP(H)` 時計算，否則記「不內插」。
- CI 用同樣的種子和抽樣次數，以串流為單位抽樣，三組用同一批串流。抽到不滿足上述條件的樣本不算，並報告可計算的比例。
- CI 下界大於 0 記「高於連線」，上界小於 0 記「低於連線」，其餘記「沒有差別」。
- **讀法：** 連線假設 leader 訊號的誤報－超額命中關係在 H3 和 H 之間是直線。B2 的曲線在這一段並不平滑（第四節），所以連線可能高估或低估 leader，這項只當描述，不改變任何判定。

### 次要假說

- **突變與漸變。** 每個資料集分突變、漸變兩半，短窗和長窗各算一次 G3 對 H3 的 `ΔX`。CI 下界大於 0 記「G3 較多」，上界小於 0 記「G3 較少」，其餘記「沒有差別」。
- **準確率。** `Δacc` 是兩組整條串流準確率的差，以可計分預測數加權，每次抽樣重算。CI 全正記「較好」，全負記「較差」，其餘記「持平」。主判定和每個次要判定的母體上各算一次。

### 只描述、不判定

- 各資料集、各組、各 cell、各注入方式的 FP、命中、C、X、MDT、準確率，短窗和長窗都列。
- 警告的開啟、確認、逾時、離區關閉次數，訓練暫停的總步數，執行時間。
- 和 DET7 的數字並排。trial 和機器不同，只比方向。

## 六、事前預測

根據是 B2 重播的比例（leader 從 0.001 調到 3e-4，誤報約剩一半、X 約剩 0.87）套到 DET7 的 H 上，再和 DET7 的 G3 相比。重播不是真實 pipeline，所以只當方向。

- **主判定：** P1 不成立（G3 誤報較多）、P2 成立（G3 超額命中較多），結論「有得有失」。
- **連線檢查：** electricity「沒有差別」，點估計為正。
- **covertype：** P1 成立、P2 不成立，「有得有失」。**gas：** P1 持平、P2 持平，「持平」。
- **長窗：** electricity P1 持平、P2 成立，「持平」；covertype「有得有失」；gas「持平」。
- **H3 對 H：** 三個資料集 P1 都成立；P2 都持平；結論都是「持平」。
- **G3 對 H（重做 DET7）：** electricity「持平」（P1 成立、P2 持平）；covertype「有得有失」；gas「持平」。
- **三資料集合併：** P1 成立、P2 持平，「持平」。
- **突變與漸變：** electricity 突變「G3 較多」；covertype 兩半「G3 較少」；其餘「沒有差別」。
- **準確率：** covertype「較差」，其餘「持平」。
