# DET5 預註冊：另外兩個來源資料集上的 E10bFT 對 HDDM-A

**登記：** 2026-10-18（Asia/Taipei），以本文件的 commit 為準。兩組在判定資料上的任何執行，都在本文件與計分腳本提交之後才開始。本文件提交後不改寫，偏離一律追加在末尾「修訂」。

**頂層問題：** [DET3](ECPF_DET3_預註冊.md) 在單棵樹上判定 E10bFT 的偵測不優於 HDDM-A（持平）。[DET4](ECPF_DET4_預註冊.md) 換成 10 棵樹的森林，判定是不如。兩輪的主判定都只用注入漂移的 electricity。本輪改用同一套注入程式，從另外兩個來源資料集 covertype 和 gas sensor drift 產生新串流，回答兩個問題：

1. 在同一套組別和計分下，E10bFT 的偵測有沒有比 HDDM-A 好？
2. DET3 的結論換了來源資料集還成不成立？

背景來源：[DET3 預註冊](ECPF_DET3_預註冊.md)、[DET3 判定](../outputs/det3/det3_verdict.md)、[DET4 預註冊](ECPF_DET4_預註冊.md)、[DET4 判定](ECPF_DET4_判定.md)。

## 一、名詞

警報、GT、命中、誤報（FP）、碰運氣的期望命中（C）、超額命中（X）、平均偵測延遲（MDT）、整條串流準確率的定義，和 [DET3 預註冊第一節](ECPF_DET3_預註冊.md)完全相同，計分沿用同一組函式。本輪另外用到：

| 名詞 | 意思 |
|---|---|
| 主窗 | 每個 GT 起點後的 1000 步，`[d_s, d_s+1000]`，含端點 |
| 長窗 | 每個 GT 起點後的 `delta_max` 步：covertype 2500 步，gas 1500 步。這是登記檔給兩個資料集的 `delta_max`，也是注入漸變的過渡寬度 |
| cell | 一種注入方式（class_prior、label_swap、feature_permutation、feature_filtering）配一種漂移型態（abrupt、gradual），共 8 個 |
| trial | 同一個 cell 以不同亂數產生的第幾條串流，編號 g00–g49 |
| 超出碰運氣 | 一組在一個資料集上的 X（全部串流合計）的 95% CI 下界大於 0 |

## 二、組別

| 代號 | preset | 偵測方式 |
|---|---|---|
| DET5-E | `e10bft` | 兩個 ADWIN 讀凍結參照模型的損失，另加只認「變差」的 leader 守衛；警告超過 1000 步未確認就關閉 |
| DET5-H | `det1_zone_hddm_a_lw0` | HDDM-A（MOA 預設參數）的 warning 區開警告，drift 區確認 |

- **就是 DET3 的兩組。** preset 檔不修改，學習器是單棵 Hoeffding Tree。
- **兩組共同的部分：** ECPF 嚴格替換、ECPF 淘汰規則、模型池上限 10、暖機 200 筆、警告期間暫停訓練、`river==0.21.2`。
- 不調任何參數。
- **`det_adwin` 只用來描述，不參與判定。** 它是 Cerqueira et al. 的純偵測流程：一棵從不重設的 Hoeffding Tree，搭配 ADWIN（δ = 0.01），前 25% 的資料不餵給偵測器。它的用途是在同一批串流上，報出那篇論文的流程下的 F1 和 MDT，當作這兩個資料集偵測難度的參考。登記檔只列出每個 cell 論文裡最好的方法，沒有 ADWIN 自己的數字，所以它不當校準閘門。
- **不跑森林。** 主方法 `e10bft` 本身就是單棵樹，而 DET4 已經在 electricity 上回答過森林的問題。試跑時森林每條要花單棵樹的 4–5 倍時間。這是使用者 2026-10-18 看過試跑時間後的決定。

## 五、判定規則

### 主判定：兩個資料集各一個，各 320 條，主窗 1000 步

每個資料集各自判定，用的條件和 DET3、DET4 相同：

| 條件 | 量 | 成立 | 不成立 | 持平 |
|---|---|---|---|---|
| P1 誤報 | `ΔFP = FP(E) − FP(H)`，該資料集 320 條合計 | 95% CI 上界小於 0 | 下界大於 0 | 其餘，含碰到 0 |
| P2 超額命中 | `ΔX = X(E) − X(H)`，該資料集 320 條合計 | 95% CI 下界大於 0 | 上界小於 0 | 其餘，含碰到 0 |

**CI 的算法：** 每個資料集分開算。以串流為單位、兩組配對、有放回抽樣 10,000 次，種子 `20261012`，取第 2.5 和 97.5 百分位，和 DET1、DET3、DET4 相同。各組自己的 X 的 CI，用同一批抽樣算。

| P1 | P2 | 結論 |
|---|---|---|
| 成立 | 成立 | E10bFT 優於 HDDM-A |
| 不成立 | 不成立 | E10bFT 不如 HDDM-A |
| 一個成立、一個不成立 | | 有得有失：照實寫哪一項較好、哪一項較差，不下勝負結論 |
| 任一持平 | | 持平 |

**可判定性：** 如果一個資料集上兩組的 X 都沒有超出碰運氣，這個資料集的 P2 記「不可判定：兩組的命中都沒有超出碰運氣」，結論改寫成「兩組的偵測都接近碰運氣；誤報 E 較少／較多／持平」，依 P1 決定，不寫優於、不如或持平。理由是 E13 在舊版 covertype 上看過這種情形，而且論文在 covertype 上多數 cell 的最佳 F1 都低於 0.2。

**兩個資料集怎麼合起來寫：**

- 兩個主判定各自成立、各自報告。
- 兩個結論相同時，總結才寫成一句，範圍限於「單棵 Hoeffding Tree、警告期間暫停訓練、Cerqueira et al. 的注入方式、covertype 和 gas、1000 步主窗」。
- 兩個結論不同時分開寫，不合併成一個勝負，並和 DET3 在 electricity 上的結論並列。
- gas 是主方法發展期間用過的來源資料集（見第四節）。如果只有 gas 判優於，結論必須註明這一點。

### 次要判定：同一套 P1、P2，換窗或換母體

以下三個各自判定、各自標示「次要」，不改變主判定：

1. **covertype 的長窗（2500 步）。**
2. **gas 的長窗（1500 步）。**
3. **兩個資料集合計 640 條，主窗。** 分兩層、各層內抽樣後合計。

長窗的解讀規則和 DET4 相同：主判定不是「優於」而長窗是「優於」時，兩個要一起寫，不能只報長窗。主判定和次要判定方向相反時，兩邊都保留、都寫出來。可判定性的規則同樣適用於次要判定。

### 次要假說

- **H2 漸變與突變。** 每個資料集的 4 個 gradual cell（160 條）和 4 個 abrupt cell（160 條）分開算 `ΔX`，主窗和長窗各算一次。CI 下界大於 0 記「主方法較多」，上界小於 0 記「主方法較少」，其餘記「沒有差別」。
- **H3 準確率。** `Δacc` 是兩組整條串流準確率的差，以可計分預測數加權，每次抽樣重算。CI 全正記「較好」，全負記「較差」，其餘記「持平」。在兩個主判定和三個次要判定的母體上各算一次。若 P1、P2 判優於而準確率 CI 全負，結論必須寫成「偵測較好、準確率較差」；反過來也一樣。

### 只描述、不判定

- `det_adwin` 在各 cell 的 F1、precision、recall、MDT，用 Cerqueira et al. 的計分（`[d_s, d_s+delta_max]`），和登記檔的最佳方法並排。兩組在同一套計分下的同樣數字也並列。兩組會在警報後調整模型，流程和論文不同，所以只供參考。
- 各注入方式分開的 FP、命中、X。
- 警告的開啟、確認、逾時、離區關閉次數，訓練暫停的總步數，執行時間。
- 和 DET3 在 electricity 上的單棵樹結果並排。資料不同，只比合計的量級，不做檢定。

## 十、限制

- **範圍窄：** 只有單棵 Hoeffding Tree、一個亂數種子、兩個來源資料集、一套注入程式（Cerqueira et al. 的四種方式、兩種型態）。
- **gas 用過：** gas 是主方法發展期間用過的來源資料集（舊版注入檔）。本輪用新串流，能降低這個影響，但無法排除。
- **covertype 難偵測：** covertype 的注入漂移對看錯誤率的偵測器很難偵測，可能兩組都接近碰運氣，主判定因此不可判定。
- **gas 誤報機會少：** gas 每條只有 13,910 筆，前 25% 不計分、漂移在 50–80% 之間，可計分的步數約一萬，誤報的機會比 electricity 少。
- **長窗不一致：** 兩個資料集的長窗長度不同，各自取登記檔的 `delta_max`。
- **沒調參：** HDDM-A 用 MOA 預設參數，主方法的參數是在別的資料上定的，兩邊都沒有在這批串流上調參。
- **先看過結果：** 本輪是看過 DET3、DET4 之後才決定跑的。用新的串流和不變的規則來降低這件事的影響，但無法完全排除。
