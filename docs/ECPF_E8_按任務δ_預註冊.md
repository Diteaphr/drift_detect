# E8 預註冊：按任務設定 δ（保留資料驗證）

**登記：** 2026-09-28，以本文件的 commit 為準。E8 的任何執行都在這個 commit 之後。

**依據：** E7 判定為不採用，但結果分任務：分類三個家族都變好，Joe 迴歸變差（TP@3000 −4）。「分類用 0.002、迴歸維持原值」這個切法是**看過 E7 的分家族結果才提出的**。如果在同一批串流上跑，分類會重現 E7、迴歸會重現 E2-k500（執行是決定性的），等於自己驗證自己。所以 E8 **只在前面各輪從未用過的保留串流上**判定。

## 臂

兩臂都在五個保留家族上跑：

- **E2k500：** δ 0.05／0.1（現行主設定）。
- **E7：** δ 0.002／0.004。

「按任務設定 δ」的規則，就等於分類家族取 E7、迴歸家族取 E2k500。程式不改，river 0.21.2，主計分用 3000 步窗（理由同 E7）。

## 判準

**(a) 分類效益能否重現**（B-ho、MC-syn-ho、MC-RBF-ho），三項都成立才算通過：
1. 三個分類家族合計的 FP@3000，E7 比 E2k500 降 ≥ 30%；
2. 每個家族的 TP@3000 損失 ≤ 1；
3. 每個家族的準確率不低於 E2k500 超過 0.005。

**(b) 迴歸是否真的該維持原 δ**（REG-syn-ho、REG-Joe-ho）：若 E7 在任一迴歸家族損失 TP@3000 超過 1 個，或迴歸合計 FP@3000 上升，就算「切分成立」；否則算「切分不成立」。

**機制（只報告）：** 分類家族中，E2k500 的 FP@3000 事件在 E7 消失的比例；事件數 ≥ 3 時預期 ≥ 50%。

**結論規則：**

| (a) | (b) | 結論 |
|---|---|---|
| 通過 | 切分成立 | **採用按任務 δ**：分類 0.002／0.004，迴歸 0.05／0.1 |
| 通過 | 切分不成立 | 按任務的切分被否證，改採**統一 δ 0.002／0.004** |
| 不通過 | — | E7 在分類上的效益沒有重現，維持**統一 δ 0.05／0.1**（E2-k500） |

1000 步窗的 TP／FP、延遲中位數與 MAE 照常報告。
