# E7 預註冊：凍結參照上的 δ 校準

**登記：** 2026-09-28，以本文件的 commit 為準。E7 的任何執行都在這個 commit 之後。

**依據：**
- E6 判定：不採用，主設定維持 E2-k500。
- 重新計分（`outputs/e1_e2/rescore.md`）：計分窗放寬到 3000 步後，E2-k500 的 FP 從 28 降到 13；REG-Joe 由 13 降到 5，差額 8 個是晚到的真命中。剩下的 13 個 FP 離任何漂移都超過 3000 步（或在第一次漂移之前），分布為 B 6、MC-RBF 1、MC-syn 1、REG-Joe 5、REG-syn 0。

## 設計

- **基線：** E2-k500，直接沿用 `outputs/e1_e2/*/E2k500`。
- **臂 E7：** E2-k500，把兩臂的 δ 改為 drift 0.002、warning 0.004。0.002 是 ADWIN 慣用值；warning／drift 的比例維持 2 倍，只改整體敏感度。相對基線只差這一個機制。
- `src/` 不改，δ 本來就是參數。矩陣與前幾輪相同（五個家族），river 0.21.2。

## 計分：晚到與誤報分開算

δ 調嚴必然讓偵測變慢。1000 步計分窗會把「晚到的真命中」同時算成一次漏抓和一次 FP，無法回答這一輪的問題。所以本輪的主判準改用 3000 步窗：

- **誤報：** 3000 步窗下的 FP。
- **召回：** 3000 步窗下的 TP。
- 延遲中位數，以及 1000 步窗下的 TP／FP，照常報告，作為與前幾輪的對照。

E6 在 3000 步窗下看起來較好（FP 13 → 7），但它的判定依其預註冊（1000 步窗）不變。E6 是否在新計分下重審，另行登記；本輪基線仍是 E2-k500。

## 判準

- **機制：** E2-k500 的 13 個 3000 步窗 FP，E7 至少讓 50% 消失（±500 步內沒有任何確認）。
- **採用：** 以下三項同時成立，E7 才取代 E2-k500 成為主設定：
  1. 五家族合計的 3000 步窗 FP 降 ≥ 30%（13 → ≤ 9）；
  2. 每個家族的 3000 步窗 TP 損失 ≤ 1；
  3. 每個家族的準確率不低於 E2-k500 超過 0.005，MAE 不高於 E2-k500 的 1.02 倍。
- **預測，只報告：** 依 ADWIN 門檻對 δ 的對數依賴推算，延遲中位數約增加 50%。1000 步窗下的 FP 可能反而增加，因為會有更多命中晚於 1000 步。準確率／MAE 的方向不預測：誤適應變少與真適應變慢兩種效應方向相反。
