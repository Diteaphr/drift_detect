# E6 預註冊：凍結參照＋原生方向閘（疊加）

**登記：** 2026-09-27，以本文件的 commit 為準。任何 E6 程式，包括前置重播，都在這個 commit 之後才執行。
**依據：** E1／E2 判定（`outputs/e1_e2/verdict.md`）。E2-k500 目前最佳，五家族合計 FP 28、TP 104。殘餘 FP 分布：B 7、MC-syn 5、MC-RBF 3、REG-syn 0、REG-Joe 13。

## 設計

- **基線：** E2-k500，直接沿用 `outputs/e1_e2/*/E2k500`。
- **臂 E6：** E2-k500 加上 `ecpf_adwin_one_sided`。兩臂的輸入都是凍結參照的損失。相對基線只多這一個機制。
- **矩陣：** 與 E0、E1E2 相同（五個家族，同一批串流、學習器、步數），river 0.21.2。
- 兩個旗標都已實作並通過閘門，`src/` 不再改動，只在 harness 加一臂。

## 前置量測（E6 執行前，離線重播，不跑 pipeline）

用 E0 的重播法，在 E2-k500 的 trace 上重現兩臂：輸入為 ref_err，確認時與參照切換時兩臂重建。每個家族得到兩個數字：

- **p_dec_ref(FP)：** 殘餘 FP 中，參照空間切點為下降的比例。
- **TP_dec_ref：** 參照空間中由下降觸發的命中數。

有效性：重播必須重現所有記錄到的觸發（不符數 0），否則不判讀。

這個量測不決定要不要跑 E6（已決定要跑），只決定下面的登記預測。若可被吸收的 FP（下降觸發者）不到合計 FP 的 30%，先登記「預測不採用」，E6 仍照跑，用來再次檢驗開環預測與閉環結果的差距。

## 判準

- **機制：** 在 FP ≥ 3 且 p_dec_ref(FP) ≥ 0.50 的家族，前置量測判為下降觸發的 E2-k500 FP，E6 至少要讓 70% 消失（±500 步內沒有任何確認）。
- **預測：** 每個家族的 FP 降幅上限約為 p_dec_ref(FP)，TP 損失約為 TP_dec_ref。p_dec_ref(FP) < 0.50 的家族登記為「預測無效」。
- **採用：** 以下三項同時成立，E6 才取代 E2-k500 成為主設定：
  1. 五家族合計 FP 降 ≥ 30%（28 → ≤ 19）；
  2. 每個家族 TP 損失 ≤ 1；
  3. 每個家族的命中延遲中位數增加 ≤ 100 步。

  任何一項不成立：維持 E2-k500 為主設定，E6 作為消融結果報告。
- **次要，只報告：** 準確率／MAE。單側閘也會去掉由下降開啟的 warning，訓練暫停可能因此減少。
