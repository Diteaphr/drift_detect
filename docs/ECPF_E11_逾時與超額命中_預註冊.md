# E11 預註冊：warning 逾時，以及扣除機率命中的召回

**登記：** 2026-09-29，以本文件的 commit 為準；本 commit 同時納入 E11 用到的新資料子集。E11 的任何執行都在這個 commit 之後。
**目的：** 修正評估方式，之後的判定才有可靠的量尺。兩件事一起處理：
1. 把卡住的 warning 關掉（warning 逾時）；
2. 召回改用扣除機率命中的「超額命中」。

在這個新標準下，重新比較 base、E1、E2-k500。
**判定資料：** 只用前面各輪（E0–E10、A1、A2）都沒用過的資料。

## 背景：E10 之後的事後分析（開發資料：A1、A2、E10）

- **卡住的 warning。** 預設沒有逾時，warning 開啟後，只有被確認才會關閉；開著的期間訓練暫停。
  - base 在 E10 資料上平均有 10–19% 的步數暫停，最長一次 50,881 步。
  - 之後真漂移的確認會被記在舊 warning 的時刻，重用的緩衝也橫跨兩個概念。
  - 已確認的偵測中，warning 到確認的間隔：真命中 95% 在 384 步內，超過 1000 步的只有 1.7%；orphan 有 19.9% 超過 1000 步，最長 50,880 步。
- **機率命中。** base 的 FP 多，計分窗又寬，不少命中只是碰巧落在窗裡。估計 E10 的 gas 上，base 的 16 個命中約有 10 個是機率命中。所以「TP ≥ base 的 90%」這類判準，對低 FP 的方法系統性不公平。
- **逾時的取值：** 使用者依上面的間隔分布選定 **T = 1000 步**。

## 新指標：超額命中（excess hits）

對每一次執行（串流 × 學習器 × 臂），計分窗 ext = 3000：

- **計分窗：** 每個計分的 GT 區間 [s, e] 延伸成 [s, e + 3000]，截到串流結尾；窗外步數 O = 暖機後總步數 − 所有窗的聯集長度。
- **誤報率：** λ = 該次執行的 FP@3000 ÷ O。
- **期望機率命中：** C = Σ_窗 (1 − exp(−λ × 窗長))，也就是誤報率相同、而且與漂移無關的偵測器平均會碰巧拿到的命中數（Poisson 近似）。
- **超額命中：** X = TP@3000 − C，合計時逐次加總。
- **自我檢查：** 在模擬的隨機偵測器上，超額命中的平均必須接近 0（|平均| < 0.3，200 次重複）。

## 臂

| 臂 | 定義 |
|---|---|
| base | 現行設定，沒有逾時；只用來量逾時本身的效果 |
| baseT | base 加上 warning 逾時 1000 步（新標準的基線） |
| E1T | E1 加上逾時 |
| E2k500T | E2-k500 加上逾時 |

- **逾時的行為：** 用 `src/` 既有的 `ecpf_detector_warning_timeout`。warning 開超過 1000 步仍未確認，就關閉 warning、丟棄緩衝、只重建 warning 臂；真的漂移會讓 warning 重新開啟。
- **程式：** `src/` 不改動，所以不需要 byte gate。
- **其餘設定**與前面各輪相同：δ 0.05／0.1、river 0.21.2、迴歸開 P3。

## 閘門

- **開跑前：** E10 資料裡卡最久的那次（gradual_sea100k_g01、ht、E2-k500，warning 開了 50,881 步）用 E2k500T 重跑，所有確認的間隔都必須 ≤ 1001 步。超額命中的自我檢查也必須通過。
- **判定前（A0，有效性）：** baseT、E1T、E2k500T 所有確認的間隔都 ≤ 1001 步；不成立則本輪無效。

## 判準

**A. 逾時本身（base 對 baseT，同一批資料配對比較）**

- **A1（不傷害）：** 四組各自的 baseT 準確率 ≥ base − 0.005（迴歸：MAE ≤ base × 1.01），而且四組合計的超額命中 baseT ≥ base 的 90%。
- **A1 成立**：逾時 1000 步成為之後各輪的標準設定。
- **A1 不成立**：照實報告，B 的結果只作參考。

**B. 方法（E1T、E2k500T 各自對 baseT；召回一律用超額命中）**

- **P1（INJ-gas）：** 合計漂移前 FP ≤ baseT 的 30%。baseT 合計至少要有 10 個，這條才可判定。
- **P2（INJ-gas）：** 合計超額命中 ≥ baseT 的 90%。
- **P3（SYN2，B、MC、REG 三組分開判）：** FP@3000 ≤ baseT 的 50%，而且超額命中 ≥ baseT 的 90%。該組 baseT 的 FP@3000 少於 6 個時，FP 部分不可判定，只判召回。
- **P4（準確率護欄，四組分開判）：** 分類的平均準確率 ≥ baseT − 0.01；迴歸的平均 MAE ≤ baseT × 1.02。
- **結論規則（同 A2）：**
  - 分類：P1、P2、P3-B、P3-MC，以及 SYN2-B、SYN2-MC、INJ-gas 的 P4 全部成立 →「在新標準下，分類成立」；
  - 迴歸：P3-REG 與 SYN2-REG 的 P4 都成立 →「在新標準下，迴歸成立」。

## 事前預測（不影響判定）

- **baseT：** 準確率高於 base，因為卡住的 warning 不再凍結訓練。原本被記在舊 warning 時刻的真命中會回到正確位置，所以 FP 下降、超額命中上升。
- **E2k500T：** 分類預期成立。迴歸取決於 FP；E10 的 E2-k500 在 REG 上 FP 7 對 base 11，恰好在 50% 門檻附近。
- **E1T：** 預期 gas 的召回仍不足，迴歸如 E0 預測無效。
