# DET7 預註冊：改用 HDDM-A 讀凍結參照（G3）對 HDDM-A

**登記：** 2026-10-20（Asia/Taipei），以本文件的 commit 為準。各組在判定資料上的任何執行，都在本文件與計分腳本提交之後才開始。本文件提交後不改寫，偏離一律追加在末尾「修訂」。

**頂層問題：** DET3 到 DET5 的四個主判定，E10bFT 在 1000 步窗內的超額命中都比 HDDM-A 少。2026-10-19 的兩次開發檢查（B2、B3-dev，見第四節）指出原因：凍結參照的訊號本身不差，慢的是讀它的雙 ADWIN。把雙 ADWIN 換成 HDDM-A 之後，在 DET3 已判定過的串流上，方向翻了過來。這些檢查都用看過的資料，而且工作點是在同一批資料上挑的，所以不能當證據。本輪用沒用過的串流回答：

1. 凍結參照改由 HDDM-A（drift 信賴度 3e-4）讀取、保留 leader 守衛（本輪稱 G3），在新的注入 electricity 串流上，偵測有沒有比 HDDM-A 好？
2. 這個結果在 covertype、gas 上是否成立？誤報和準確率付出多少代價？

背景來源：
- [DET3 預註冊](ECPF_DET3_預註冊.md)、[DET5 預註冊](ECPF_DET5_預註冊.md)、[DET5 判定](ECPF_DET5_判定.md)
- B3-dev 的程式在本機分支 `feat/b3dev-ref-hddm-a`，commit `6965dca`

## 一、名詞

以下名詞的定義和 [DET3 預註冊第一節](ECPF_DET3_預註冊.md)完全相同，計分沿用同一組函式：警報、GT、命中、誤報（FP）、碰運氣的期望命中（C）、超額命中（X）、平均偵測延遲（MDT）、整條串流準確率。本輪另外用到：

| 名詞 | 意思 |
|---|---|
| 凍結參照 | E10bFT 在每次確認漂移時凍結一份模型，500 步後再從已適應的 leader 重新凍結一次。偵測器讀的是這份凍結模型的 0/1 損失，不是 leader 的 |
| leader 守衛 | 另一組只認「變差」的雙 ADWIN，讀 leader 自己的 0/1 損失。它和讀凍結參照的偵測器任一個開警告或確認都算 |
| 短窗 | `[d_s, d_s + 1000]`，含端點，和 DET3 到 DET5 的主窗相同 |
| 長窗 | `[d_s, d_s + delta_max]`，delta_max 取各資料集登記檔的值：electricity 2500、covertype 2500、gas 1500 |
| trial | 同一個 cell 以不同亂數產生的第幾條串流，編號 gNN |
| 超出碰運氣 | 一組在一個母體上的 X（全部串流合計）的 95% CI 下界大於 0 |

## 五、判定規則

### 主判定：electricity，640 條，短窗，G3 對 H

| 條件 | 量 | 成立 | 不成立 | 持平 |
|---|---|---|---|---|
| P1 誤報 | `ΔFP = FP(G3) − FP(H)`，640 條合計 | 95% CI 上界小於 0 | 下界大於 0 | 其餘，含碰到 0 |
| P2 超額命中 | `ΔX = X(G3) − X(H)`，640 條合計，短窗 | 95% CI 下界大於 0 | 上界小於 0 | 其餘，含碰到 0 |

**CI 的算法：** 以串流為單位、兩組配對、有放回抽樣 10,000 次，種子 `20261012`，取第 2.5 和 97.5 百分位，和 DET1、DET3 到 DET6 相同。單一資料集不分層，合併多個資料集時依資料集分層。各組自己的 X 的 CI 用同一批抽樣算。

| P1 | P2 | 結論 |
|---|---|---|
| 成立 | 成立 | G3 優於 HDDM-A |
| 不成立 | 不成立 | G3 不如 HDDM-A |
| 一個成立、一個不成立 | | 有得有失：照實寫哪一項較好、哪一項較差，不下勝負結論 |
| 任一持平 | | 持平 |

**可判定性：** 和 DET5 相同。如果兩組的 X 都沒有超出碰運氣，P2 記「不可判定」，結論改寫成「兩組的偵測都接近碰運氣；誤報 G3 較少、較多或持平」，由 P1 決定。

**結論可以怎麼寫：**
- 結論用語只看上表。
- 範圍限於「注入漂移的真實資料串流、單棵 Hoeffding Tree、警告期間暫停訓練」，並註明 3e-4 是在開發資料上選的。
- 如果只有一項成立、另一項持平，結論是持平。可以照實寫哪一項單項成立，但不能寫「偵測優於 HDDM-A」。
- 主判定是「優於」而 covertype 或 gas 的次要判定是「不如」或「有得有失」時，要一起寫，不能只報主判定。
- 不論結果，都要寫明本輪沒有重測多漂移的合成資料，而那是 B3-dev 看到的弱點（第十節）。

### 次要判定

以下各項用同一套 P1、P2 和可判定性規則，各自判定、各自標示「次要」，不改變主判定：

1. **covertype，320 條，短窗，G3 對 H。**
2. **gas，320 條，短窗，G3 對 H。**
3. **長窗：** 三個資料集各一次，G3 對 H。
4. **預設工作點：** electricity，短窗，G 對 H。這一項沒有在開發資料上調過參，用來看 3e-4 的選擇偏誤。
5. **和現行主方法比：** electricity，短窗，G3 對 E。
6. **三資料集合併：** 1,280 條，短窗，G3 對 H，依資料集分層。

主判定和次要判定方向相反時，兩邊都保留、都寫出來。

### 次要假說

- **H2 突變與漸變。** 每個資料集分突變、漸變兩半，短窗和長窗各算一次 G3 對 H 的 `ΔX`。CI 下界大於 0 記「G3 較多」，上界小於 0 記「G3 較少」，其餘記「沒有差別」。
- **H3 準確率。** `Δacc` 是兩組整條串流準確率的差，以可計分預測數加權，每次抽樣重算。CI 全正記「較好」，全負記「較差」，其餘記「持平」。主判定和每個次要判定的母體上各算一次。

### 只描述、不判定

- 各資料集、各組、各 cell、各注入方式的 FP、命中、C、X、MDT、準確率，短窗和長窗都列。
- 警告的開啟、確認、逾時、離區關閉次數，訓練暫停的總步數，執行時間。
- 和 B3-dev 在 DET3 資料上的數字並排。資料不同，只比方向。

- **gas：** P1 持平、P2 持平，結論「持平」。
- **長窗：** electricity「優於」；covertype、gas「持平」。
- **G 對 H：** P1 持平、P2 成立，結論「持平」。
- **G3 對 E：** 「優於」。
- **三資料集合併：** P1 成立、P2 持平，結論「持平」。
- **H2：** electricity 突變「G3 較多」，其餘「沒有差別」。
- **H3：** 全部持平。
