# E1＋E2 預註冊（同輪）

**登記日期：** 2026-09-27，執行前。**依據：** E0 判定（`outputs/e0_native_direction/verdict.md`；預註冊見 `docs/ECPF_E0_原生切點方向_預註冊.md`）：D1 部分 GO，D2 同輪。

## 臂

矩陣與 E0 相同：五個家族、同一批串流、學習器與步數，river 0.21.2。每一臂相對基線只差一個機制。

| 臂 | 唯一差異 |
|---|---|
| base | E0 的執行（B、MC 為 E0 重跑，REG 為封存；迴歸各臂 P3 皆開） |
| E1 | ADWIN 原生方向閘：兩臂都套、放在 adapter 內、MOA 語意（切窗後估計值未上升就不回報，並保留切窗後視窗）。旗標 `ecpf_adwin_one_sided` |
| E2-k0 | 凍結參照 k = 0（主臂）。分類為本輪新擴充：偵測器讀凍結複本的 0/1 損失；迴歸沿用既有實作 |
| E2-k500 | 凍結參照 k = 500（次臂） |

事件配對：若 ±500 步內沒有任何確認，就算基線事件在該臂「消失」。

## E1 判準

- **機制：** 在 p_dec ≥ 0.50 的家族（B、MC-syn、MC-RBF、REG-syn），E0 判為下降觸發的基線 FP 中，E1 至少要有 70% 消失。
- **總體：** FP 降幅 B、MC-syn、REG-syn ≥ 40%，MC-RBF ≥ 30%。每家族 TP 損失 ≤ 容許量（B 1、MC-syn 3、MC-RBF 11、REG-syn 1、REG-Joe 4）。命中延遲的中位數增加 ≤ 100 步。
- **失敗：** 任一家族 TP 歸零；或預測有效的家族 FP 降幅 < 20%。
- **REG-Joe 預測無效：** 若 FP 降幅 > 20%，必須以閉環效應解釋，不算 E1 的機制功勞。
- **次要（E0 M4）：** MC-syn、MC-RBF 的準確率 E1 ≥ base。

## E2 判準（k = 0 為主）

- **H1：** 在 REG 家族，E2 的 FP ≤ E1 的 FP − 2，而且 E0 M3 目標集合（20 個正規化器追趕事件）至少有 50% 在 E2 消失。
- **H2：** 在 E0 D2 稽核清單的執行上（20 個下降觸發命中所在的「串流 × 設定」），E2 的 TP 合計 ≥ E1 的 TP 合計 + 1。
- **判定：** H1 或 H2 成立，凍結參照保留為主方法的候選；兩者都不成立，E1 為主機制，凍結參照降為分析工具。
- **k = 500：** 合計比 k = 0 少 ≥ 2 個 FP、TP 不少於 k = 0，而且沒有任何「被切換關掉、年齡 ≥ 100 步、開始於 GT 窗內」的 warning，才保留兩階段設計。
- 凍結參照的 z_ref 機制判準（v4）門檻仍待重新登記，本輪不判；輸出保留，之後可用 `scripts/analyze_reference_signal.py` 補做。

## 閘門（執行前必須通過）

- **旗標預設關：** binary byte gate 通過（`run_ecpf_recurring.py`，`detector`／`meta_ecpf_gddm`／`meta_ecpf_hier_parallel`，`recurring_sud_sea100k_g00`，16000 步，事件 CSV 的 SHA256 與改動前相同）。另外每個家族抽一次基線重跑，偵測序列必須與 E0 或封存相同，基線才可重用。
- **E1 自我檢查：** 人造的階梯下降序列不得觸發，階梯上升必須觸發。
