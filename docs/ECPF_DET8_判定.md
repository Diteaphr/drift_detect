### 變因

- **自變因：** 偵測方式。三組都用單棵 Hoeffding Tree。
  - **G3（受測）** = preset `det7_g3`，和 DET7 相同。HDDM-A（drift 3e-4、warning 1.5e-3）讀凍結參照的損失；另加 leader 守衛；警告超過 1000 步沒有確認就關閉。
  - **H3（對照）** = `det8_h3`。HDDM-A（drift 3e-4、warning 1.5e-3）讀 leader 的損失；沒有守衛、沒有逾時。它只比 H 多一個設定欄位 `ecpf_zone_drift_confidence: 0.0003`。
  - **H（第三組）** = `det1_zone_hddm_a_lw0`。HDDM-A 預設參數（drift 0.001、warning 0.005）讀 leader 的損失。
  - G3 和 H3 用同一個工作點，但 G3 另有守衛、逾時和凍結守衛尺度。所以主判定比的是「E10bFT 的整套機制」對「只讀 leader」。
- **判定用的依變因：** FP 和 X 用在主判定、次要判定、突變與漸變；準確率用在準確率假說。
- **只描述的依變因：** 命中、MDT、kappa、連線檢查、警告的開啟與關閉次數、訓練暫停步數、執行時間。
- **控制變因：** ECPF 嚴格替換、ECPF 淘汰規則、模型池上限 10、暖機 200 筆、警告期間暫停訓練、`river==0.21.2`、同一個快照、同一台機器。沒有在判定資料上調任何參數。

### 判定規則（登記時固定）

- **P1 誤報：** `ΔFP = FP(受測) − FP(對照)`，母體內合計。95% CI 上界小於 0 記「成立」，下界大於 0 記「不成立」，其餘記「持平」。
- **P2 超額命中：** `ΔX = X(受測) − X(對照)`，母體內合計。CI 下界大於 0 記「成立」，上界小於 0 記「不成立」，其餘記「持平」。
- **CI：** 以串流為單位、兩組配對、有放回抽樣 10,000 次，種子 `20261012`，取第 2.5 和 97.5 百分位。單一資料集不分層，合併時依資料集分層。
- **結論：** 兩項都成立是「優於」，兩項都不成立是「不如」，一項成立、一項不成立是「有得有失」，任一項持平就是「持平」。
- **可判定性：** 兩組的 X 都沒有超出碰運氣時，P2 記「不可判定」。
- **主判定：** electricity，640 條，短窗，G3 對 H3。範圍限於「注入漂移的真實資料串流、單棵 Hoeffding Tree、警告期間暫停訓練、HDDM-A 3e-4」，並註明 3e-4 是看過開發資料後替凍結參照挑的。
- **次要判定：** 同一套規則，各自判定，不改變主判定。1 covertype、2 gas（短窗，G3 對 H3）；3 三個資料集的長窗；4 只調工作點（H3 對 H，三個資料集）；5 重做 DET7（G3 對 H，三個資料集）；6 三資料集合併。
- **連線檢查：** 每個資料集各一次，短窗。CI 抽樣方式同上，抽到不能內插的樣本不算，並報告可計算的比例。CI 下界大於 0 記「高於連線」，上界小於 0 記「低於連線」，其餘記「沒有差別」。只描述，不改變任何判定。
- **突變與漸變：** 每個資料集分兩半，短窗和長窗各算 G3 對 H3 的 `ΔX`。CI 下界大於 0 記「G3 較多」，上界小於 0 記「G3 較少」，其餘記「沒有差別」。
- **準確率：** `Δacc` 是兩組整條串流準確率的差，每次抽樣重算。CI 全正記「較好」，全負記「較差」，其餘記「持平」。

## 二、背景與動機

**問題。** DET7 的 G3 在三份注入資料上誤報都比 HDDM-A（H）少，electricity 的超額命中沒有差別。但 G3 的 HDDM-A 用 3e-4，H 用預設的 0.001。DET7 的次要判定 4 已經顯示，G3 換回預設參數時誤報比 H 還多。所以 DET7 分不出 G3 的誤報優勢是來自 E10bFT 的機制（凍結參照、守衛、逾時），還是只來自比較保守的工作點。

**本輪要回答的三件事：**

1. 同樣用 HDDM-A 3e-4，G3 的偵測有沒有比只讀 leader 的 H3 好？
2. 只把 HDDM-A 調保守（H3 對 H），能不能得到 DET7 裡 G3 對 H 的誤報優勢？
3. 在相同誤報下，G3 是否比 leader 訊號抓得多（連線檢查）？

**登記時已經知道的事：** DET1 到 DET7 的全部結果；B2 重播裡 leader 在 3e-4 的數字（DET3 的 160 條上 FP 37、命中 35、X 33.90，對凍結參照的 48、46、44.57）；B2 的 leader 曲線不平滑，所以連線可能高估或低估 leader；H3 在 g199 上的試跑時間。

**登記時不知道的事：** 任何一組在 g200 以後的結果；H3 在任何判定資料上的結果。

**事前預測（登記時寫下）：**

- **主判定：** P1 不成立（G3 誤報較多）、P2 成立，結論「有得有失」。
- **連線檢查：** electricity「沒有差別」，點估計為正。
- **covertype：** 「有得有失」（P1 成立、P2 不成立）。**gas：** P1、P2 都持平，「持平」。
- **長窗：** electricity P1 持平、P2 成立，「持平」；covertype「有得有失」；gas「持平」。
- **H3 對 H：** 三個資料集 P1 成立、P2 持平，都是「持平」。
- **G3 對 H：** electricity「持平」（P1 成立、P2 持平）；covertype「有得有失」；gas「持平」。
- **合併：** P1 成立、P2 持平，「持平」。
- **突變與漸變：** electricity 突變「G3 較多」；covertype 兩半「G3 較少」；其餘「沒有差別」。
- **準確率：** covertype「較差」，其餘「持平」。

**登記的程序。** 使用者 2026-10-20 要求「寫 DET8（H3 對 G3）的預註冊 在 node1 跑」。組別、資料和計分窗由登記人提出，預註冊在登記前沒有經過使用者逐條審閱，這一點在預註冊第二節已經寫明。

## 五、局限性與衍生問題

**局限：**

- **G3 和 H3 不只差在訊號：** 守衛、逾時和凍結守衛尺度也不同。主判定「持平」說的是整套機制，不能拆成凍結參照本身的效果。
- **3e-4 是替凍結參照挑的：** 對 leader 訊號不一定是好的工作點。H3 在 electricity 的 X 比 H 少，表示 3e-4 對 leader 來說可能太保守。
- **連線檢查假設直線：** B2 的 leader 曲線在這一段不平滑，連線可能高估或低估 leader。gas 只有 84.5% 的抽樣可以計算。
- **沒有多漂移的合成資料、沒有森林：** 和 DET7 相同。
- **注入資料只有三份來源：** electricity、covertype、gas。
- **機器和 DET7 不同：** G1 確認環境和 main 的結果逐位元相同，和 DET7 的數字只比方向。
- **登記前沒有經過使用者審閱：** 預註冊由登記人依要求寫成後直接提交執行。
- **計分不是 harness 協定：** 和 DET3 到 DET7 相同，用 DET1 的窗規則和超額命中。

**衍生問題：**

- covertype 的 feature_permutation 上，G3 為什麼比 leader 訊號少抓一半？DET7 和本輪都一樣。
- 只看凍結參照訊號本身（不加守衛和逾時）的 HDDM-A 3e-4，會落在連線的哪裡？
- G3 在 electricity 上訓練暫停較多，但準確率沒有變差，暫停多的部分是發生在哪些警告？

**下一步（都還沒做）：**

1. **論文的寫法：**
   - 不能把 G3 寫成凍結參照的改進。在相同工作點下，G3 在 electricity、gas 上和只讀 leader 的 HDDM-A 沒有差別，在 covertype 上抓得較少。
   - DET7 的「誤報較少、超額命中不輸 HDDM-A」要改寫成「把 HDDM-A 調到 3e-4 的效果」。
2. **決定主方法要不要換成 G3。** DET7 給出的理由在本輪不成立，換或不換由使用者決定。
3. **如果要拆出訊號本身：** 加一組凍結參照、不加守衛和逾時的 HDDM-A 3e-4，在 electricity g120–g198 或 covertype、gas g90–g198 上另外登記。
4. **拆開 covertype 的差距：** 用本輪和 DET7 已有的逐條結果，看 feature_permutation 上三組的警告時間。這是事後分析，只能當開發證據。
