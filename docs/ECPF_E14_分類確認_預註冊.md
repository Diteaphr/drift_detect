# E14 預註冊：分類確認輪

**登記：** 2026-10-01，以本文件的 commit 為準。資料以 `data/manifests/E14.txt`（檔案清單與雜湊）登記，檔案本身不入庫。E14 的任何執行都在這個 commit 之後。
**目的：** 確認主方法 E10bFT 在分類上是否成立。成立的話，分類與迴歸可以宣稱共用同一套設定。
**判定資料：** 只用前面各輪（E0–E13、A1、A2、D1、D2、C1、第 0 步）都沒用過的資料。

## 背景

- **E12：** E10bT 在分類成立，並取代 E2k500T 成為分類主方法。
- **E13：** E10bFT 取代 E2k500T 成為迴歸主方法。E10bFT 在分類上與 E10bT 逐筆相同（E13 閘門 G3）。但 E10bT 在 E13 的分類不成立：注入 electricity 的超額命中 23.6，門檻 24.3（baseT 27.0 的 90%），差 0.7；其餘分類判準全部通過。
- **因此：** 分類的結論目前是一輪成立（E12）、一輪以極小差距不成立（E13）。統一的主張需要再一輪新資料決定。
- **E13 的事後描述（未登記）：** electricity 的短缺主要在 ht（超額命中 11.3，baseT 14.2），hf10 幾乎持平（12.3 對 12.9）。

## 臂

| 臂 | 定義 |

| baseT | 雙向 dual ADWIN 讀 leader 的損失，加 1000 步逾時（基線） |
| **E10bFT** | 主方法：凍結參照 k = 500、leader 守衛、1000 步逾時、迴歸守衛凍結尺度。分類上等同 E10bT |

- **程式：** 兩臂都只用既有旗標，程式不改動，不需要 byte gate。分類上 E10bFT 與 E10bT 相同已由 E13 的 G3 驗證。
- **其餘設定**與前面各輪相同：δ 0.05／0.1、warning 期間暫停訓練（有逾時）、river 0.21.2（Anaconda）。

## 計分

同 E11–E13：標籤一律用 `classify()`，判準用 3000 步窗，召回用**超額命中**；漂移前 FP 只用於注入組。

## 判準

**A0（有效性）：** 兩臂所有確認的間隔（warning 開啟到確認）都 ≤ 1001 步；不成立則本輪無效。

**B（E10bFT 對 baseT；同 E13 的分類判準）：**
- **P1（INJ-elec）：** 合計漂移前 FP ≤ baseT 的 30%。baseT 少於 10 個時不可判定，不計入。
- **P2（INJ-elec）：** 合計超額命中 ≥ baseT 的 90%。
- **P3（SYN2-B、SYN2-MC 分開判）：** FP@3000 ≤ baseT 的 50%，而且超額命中 ≥ baseT 的 90%；該組 baseT 的 FP@3000 少於 6 時只判召回。
- **P4（三組分開判）：** 準確率 ≥ baseT − 0.01。

**主讀法：**
- **全部通過 → 分類確認成立。** 主方法統一為 E10bFT 一套設定：迴歸依 E13，分類依 E12 與 E14。報告時註明分類在三輪新資料中兩輪成立（E12、E14）、一輪未過（E13）。
- **任一條不過 → 不宣稱統一。** 報告未過的判準。
  - 若未過的是 INJ-elec 的 P2（連續兩輪），登記為主方法的**邊界條件**：在注入 electricity 上，E10bFT 的召回低於 baseT 的 90%。
  - 合成組的 P3、P4 若通過，合成分類的結論不受影響。

**次要讀法（只報告，不改變主讀法）：**
- **S1 學習器拆分（INJ-elec）：** ht 與 hf10 分別計算 E10bFT 的超額命中 ÷ baseT。一個 ≥ 0.9、另一個 < 0.9 時，讀為「短缺綁定在學習器」。
- **S2 E13 與 E14 合併（INJ-elec）：** 兩輪 electricity 合計（E13 的 E10bT 在分類上與 E10bFT 相同），報告合計的 P1、P2。
- **S3 注入方法拆分：** 四種注入方法各自的超額命中與漂移前 FP，兩臂並列。

## 事前預測（不影響判定）

- **SYN2-B、SYN2-MC：** E10bFT 通過（E11–E13 每一輪都通過，FP 都在 baseT 的三成以下）。
- **INJ-elec P2：** 不確定，接近門檻。E13 差 0.7；A1（無逾時）的凍結參照則明顯高於 base。若 S1 顯示短缺只在 ht，代表與學習器有關，而不是凍結參照本身的問題。
